# Prerequisites

You do not need to be a professional developer. You do need patience and a willingness to run commands when working locally.

## Accounts (free tiers are fine)

| Service | Used for |
|---------|----------|
| GitHub | Store your project code |
| Vercel | Host the public website (portfolio pack) |
| Supabase | Database and login (supabase-intro pack only) |

## Software (local mode)

| Tool | Purpose |
|------|---------|
| Node.js LTS | Run the site on your computer |
| Git | Version control (often installed with GitHub Desktop) |
| Code editor | Optional but helpful (VS Code, Cursor, etc.) |

Check Node:

```cmd
node -v
npm -v
```

On Windows PowerShell, if `npm` fails, try `npm.cmd`.

## Chat-only mode

You can start without Node if you use **`docs/00b-chat-only.md`**. You will hit limits before deploy; plan to move to local mode later.
