# Glossary (quick lookup)

For longer explanations see **`07-git-local-github-vercel.md`**, **`08-clis-and-plugins.md`**, and **`09-stack-plain-english.md`**.

| Term | Meaning |
|------|---------|
| Repository (repo) | A project folder tracked with Git, often on GitHub |
| Git | Tool on your computer that records snapshots of file changes |
| GitHub | Website that hosts copies of repos and collaboration |
| Clone | Download a repo to a folder on your computer |
| Commit | Save a snapshot in Git |
| Push | Upload commits to GitHub |
| Branch | A line of work (usually `main`) |
| Local | On your laptop (not the public internet) |
| Build | Turn source code into files ready to host (`npm run build`) |
| Deploy | Publish the built site (often Vercel) |
| CLI | Command-line program (`git`, `gh`, `supabase`, `npm`) |
| npm | Node package manager; installs libraries and runs scripts |
| Node.js | Runtime that powers npm and local dev/build |
| TypeScript | JavaScript plus type checking (`.ts`, `.tsx` files) |
| React | UI components library |
| Next.js | React framework with routes and production build |
| Frontend | What runs in the browser |
| Backend | Server and database logic (Supabase for beginners) |
| SQL | Language for database tables and queries |
| Postgres | Database engine Supabase uses |
| Supabase | Hosted auth + Postgres + dashboard |
| RLS | Row Level Security: per-user data access rules |
| Auth | Login and identity |
| Environment variable | Config or secret outside code (`.env.local`, Vercel settings) |
| Migration | SQL change stored in a file and applied in order |
| API | Way for code to request data over HTTP |
| JSON | Text format for structured data |
| Vercel | Hosting that builds from GitHub and serves a public URL |
| Extension / plugin | Extra feature inside your code editor (example: Supabase sidebar) |
