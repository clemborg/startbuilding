# Glossary

Short definitions for non-developers.

| Term | Meaning |
|------|---------|
| Repository (repo) | A project folder tracked with Git, often on GitHub |
| Commit | A saved snapshot of your changes |
| Push | Upload commits to GitHub |
| Clone | Download a copy of a repo |
| Branch | A line of work (usually `main` for production) |
| Build | Compile the site into files ready to host |
| Deploy | Put the built site on a public server (Vercel) |
| Environment variable | Secret or config value outside your code (API keys) |
| Frontend | What runs in the browser (pages, buttons) |
| Backend / database | Where data is stored (Supabase Postgres) |
| Auth | Login and identity |
| RLS | Row Level Security: database rules so users only see their own rows |
| API route | Server code that responds to HTTP requests |
