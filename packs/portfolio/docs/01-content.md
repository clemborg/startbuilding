# Content

All public copy lives in **`content/site.ts`**.

## Start from the example

1. Copy `content/site.example.ts` to `content/site.ts` if `site.ts` does not exist yet.
2. Replace placeholders with the user's real information.

## Résumé or paste

If the user supplies a résumé or bullet list:

1. Extract employers, titles, dates, and projects into the typed structures in the example file.
2. **Stop and ask the user to confirm** every employer name and date range before treating as final.
3. Do not add metrics unless the user confirms they are accurate and publishable.

## Tone

Matter-of-fact. No hype.
